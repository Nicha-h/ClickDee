# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through GitHub's [private vulnerability reporting](https://github.com/Nicha-h/ClickDee/security/advisories/new) ("Report a vulnerability" under the repository's **Security** tab). Include steps to reproduce and the impact you observed.

You'll get an acknowledgement within a few days. Please give us reasonable time to fix the issue before disclosing it publicly.

## Scope

Only the latest code on `main` is supported.
